# PlotterPDF Windows package

1. Run `PlotterPDF_GUI.exe` for the graphical application.
2. Run `plotter-pdf-self-check.exe` in PowerShell before connecting hardware.
3. For preview: select `examples\simple_square.svg`, choose an output folder, click **Preview**.
4. Choose a COM port only after Windows shows the GRBL device in Device Manager.
5. Before **Draw**, lift the pen, secure the sheet, clear the work area, run preview/preflight, then confirm the safety dialog.
6. If Inkscape, Word or KOMPAS are missing, PDF/SVG core workflows still work; Word/KOMPAS conversions require the installed Windows applications.
7. Test emergency release with no pen/paper first: use **Safe park / release motors** and **Emergency stop** from the GUI/CLI workflow.
