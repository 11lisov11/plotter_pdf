# Windows quick start

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev,gui,photo]"
plotter-pdf-self-check
plotter-pdf-gui
```

Use `examples\simple_square.svg` from the release zip for first preview. Do not click Draw until preview/preflight is OK and the machine area is clear.
