# GUI

Run:

```powershell
plotter-pdf-gui
```

Select input PDF/SVG/DOC/DOCX/FRW/CDW, output folder, sheet format, pass grid, tool, quality and draw order. **Preview** and **Generate G-code** are offline. **Draw** is enabled only when input, COM, preflight and confirmation are present. Runtime settings are saved to `config/gui_settings.json`, which is ignored by git.
