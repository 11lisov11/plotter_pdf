# PlotterPDF examples

This folder contains small files for a first dry-run check.

Recommended first test:

```powershell
.\plotter-pdf.exe examples\simple_square.svg --preview --sheet-format a4
```

Before drawing on real hardware, run:

```powershell
.\plotter-pdf.exe self-check
```

Do not connect or move real hardware until COM port, pen-up state, sheet fixation, and the work area are verified.
