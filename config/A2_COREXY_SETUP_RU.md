# Станок 2: A2 CoreXY

Профиль в программе: `a2_corexy` (`Станок 2 — плоттер A2 CoreXY`).

Параметры перенесены из комплекта `A2core`:

- контроллер: GRBL 1.1f;
- подключение: USB-UART CH340, `115200` бод;
- кинематика: CoreXY, преобразование моторов выполняет прошивка GRBL;
- рабочая область: `X 0..390 мм`, `Y 0..580 мм`;
- поднятое перо: `Z=0 мм`;
- опущенное перо: `Z=-4 мм`;
- скорость Z: `2000 мм/мин`;
- безопасная скорость XY: `1500 мм/мин`;
- возврат после задания: `X0 Y0 Z0`.

## Первый запуск

1. Установить драйвер CH340 из `A2core/2 第2步安装驱动 first load arduino drive soft/`.
2. Подключить только второй станок и запустить `PlotterPDF_GUI.exe`.
3. Выбрать `Станок 2 — плоттер A2 CoreXY`. Программа автоматически выберет лист и калибровку A2.
4. Убедиться, что в поле COM появился порт с подписью `CH340`, `wch.cn` или `USB-SERIAL`.
5. Поднять перо вручную и выполнить только предпросмотр/генерацию G-code.
6. Для первой проверки использовать `A2core/测试图 test msg/三弓线.svg`.
7. Проверить четыре угла A2 без установленного пера, затем повторить с пером над черновым листом.
8. Только после проверки направлений X/Y и уровней Z запускать полноценное рисование.

## Важно

- Программа не меняет GRBL-параметры `$0..$132` автоматически.
- Не запускайте одновременно PlotterPDF, GRBL-Plotter и 奎享 на одном COM-порту.
- Если движение по X или Y физически направлено неверно, сначала исправьте подключение/направление в прошивке по видео `A2core/1 第1步说明视频, introduce video/4 额外内容机器方向调整.mp4`. Не отражайте исходный чертёж.
- Профиль первого A4-станка не изменён: его скорости и положительное направление Z сохранены отдельно.
